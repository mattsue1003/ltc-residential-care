# 長照住宿機構照護紀錄系統

給住宿式長照機構與老人福利機構（養護型）使用的照護紀錄網頁。評估、紀錄、到期提醒、品質指標、評鑑準備、A4 列印都在同一頁完成。

**線上使用：** https://mattsue1003.github.io/ltc-residential-care/

## 特色
- **到期提醒**：依評鑑指標自動算出逾期與快到期的工作，例如入住 72 小時評估、定期評估、醫師巡診、藥師、家屬電訪、體重、約束同意書。
- **評估量表**：巴氏量表、SPMSQ、GDS-15、MNA-SF、Morse、Braden、疼痛、社會心理。自動計分與判讀，並產生紀錄敘述與照顧計畫建議。
- **每日照護**：手機床邊模式一次一床；每 2 小時翻身與如廁紀錄；照護紀錄支援 DAR／SOAP。
- **批次登錄**：醫師巡診、藥師、家屬電訪、體重、疫苗。
- **評鑑對應**：115 年度老人福利機構評鑑指標，也可切換為住宿式長照機構評鑑基準。另有品質指標季分析、約束管理、異常事件。
- **個資保護**：資料只存在使用者自己的瀏覽器（IndexedDB），不上傳網路，可設密碼 AES-256 加密，也可自動存檔到指定資料夾。網頁的內容安全政策禁止任何對外連線。

> 示範資料皆為虛構。正式使用前，請先在「設定與備份」設定密碼，並定期備份。

## 開發
- `python3 build.py`：把 `src/` 合併成單一檔案，輸出到 `docs/index.html`（GitHub Pages）與 `dist/`。
- `cloud/`：雲端版（Firebase 台灣機房，端對端加密、帳號與兩步驟驗證）的安全規則與部署設定，說明見 `雲端上線步驟.md`。
